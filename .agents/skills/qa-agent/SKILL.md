# QA Specialist Skill

Ative esta skill quando a tarefa envolver:
- Criação e execução de testes automatizados (frontend e backend).
- Validação de estabilidade e prevenção de regressão antes de commits.
- Testes de fluxos críticos (login, filtros, paginação, exclusão e relatórios PDF).
- Testes de cenários de borda (valores nulos, divisões por zero, caracteres especiais).

## Comandos Úteis
- Suíte completa de frontend: `npm test -- --run`
- Testes do backend: `pytest`
- Build de validação: `npm run build`
