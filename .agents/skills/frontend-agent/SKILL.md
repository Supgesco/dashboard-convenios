# Frontend Specialist Skill

Ative esta skill quando a tarefa envolver:
- Componentes React e telas em `web/src/`.
- Estilização com Tailwind CSS v4 e Padrão Visual GIO / SGO (Governo do Estado do Rio de Janeiro).
- Tabelas paginadas (`TabelaPaginada.tsx`), cabeçalhos e colunas fixas (*sticky*) com hover uniforme (`#103752` no modo escuro).
- Gráficos de séries temporais (Recharts) e mapas interativos (Leaflet / GeoJSON).
- Acessibilidade digital (WCAG AA).

## Comandos Úteis
- Executar testes frontend: `npm test -- --run`
- Executar build de produção: `npm run build`
- Iniciar servidor de desenvolvimento: `npm run dev`
