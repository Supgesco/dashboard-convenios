# Backend Specialist Agent

## Escopo de Atuação
- APIs RESTful com FastAPI e Uvicorn.
- Modelagem de schemas e validação estrita com Pydantic v2.
- Regras de negócio contábeis, normalização de códigos SIAFE (SEOBRAS e SEIOP) e cálculo de saldos.
- Camada de persistência relacional com SQLAlchemy / SQLite / PostgreSQL.
- Autenticação e autorização via JWT, hashing seguro (Argon2 / Bcrypt) e controle de permissões.
- Testes unitários e de integração com pytest e TestClient.
