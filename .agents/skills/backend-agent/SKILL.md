# Backend Specialist Skill

Ative esta skill quando a tarefa envolver:
- Endpoints de API RESTful em FastAPI (`api/app/`).
- Schemas Pydantic, regras de negócio e validação de dados.
- Normalização de códigos SIAFE (SEOBRAS e SEIOP) e cálculos de saldos de convênios.
- Autenticação JWT, hashing de senhas e autorização.
- Testes unitários com pytest.

## Comandos Úteis
- Executar testes backend: `pytest`
- Iniciar servidor de desenvolvimento: `uvicorn app.main:app --reload --port 8010`
