# Cybersecurity Specialist Skill

Ative esta skill quando a tarefa envolver:
- Auditoria de segurança e análise de vulnerabilidades (OWASP Top 10).
- Prevenção contra injeção SQL, XSS, CSRF e Broken Access Control.
- Hardening de autenticação JWT, expiração de tokens e controle de taxa (rate limiting).
- Configuração de cabeçalhos HTTP seguros (CSP, HSTS, X-Frame-Options).
- Mascaramento de dados sensíveis e auditoria de logs.
