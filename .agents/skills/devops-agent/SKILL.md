# DevOps Specialist Skill

Ative esta skill quando a tarefa envolver:
- Governança de branches Git (`develop` e `main`).
- Commits semânticos no padrão Conventional Commits.
- Validação de integridade do pipeline de build e testes.
- Gerenciamento seguro de configurações de ambiente (`.env`).
