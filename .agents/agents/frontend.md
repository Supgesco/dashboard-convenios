# Frontend Specialist Agent

## Escopo de Atuação
- Desenvolvimento de interfaces em React, TypeScript e Vite.
- Conformidade estrita com o Design System Oficial GIO / SGO (Governo do Estado):
  * Paleta oficial em modo claro e escuro uniforme (Midnight Blue `#103752` no hover da tabela).
  * Telas de Login, Visão Geral, Convênios, Municípios, Prestação de Contas, Tomada de Contas e Cargas.
  * Tabelas paginadas fluidas com cabeçalhos e colunas fixas (*sticky*) sem quebras visuais.
  * Acessibilidade digital (WCAG AA): navegação completa por teclado, contraste e leitores de tela.
  * Mapas temáticos interativos (Leaflet / GeoJSON) e gráficos de séries temporais (Recharts).
- Testes unitários de interface com Vitest e React Testing Library (`npm test -- --run`).
- Validação contínua do build de produção (`npm run build`).
