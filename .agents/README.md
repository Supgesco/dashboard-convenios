# Squad de Agentes Especialistas - Dashboard de Convênios (GIO)

Este diretório contém a definição do squad de agentes autônomos especializados do projeto:

| Agente | Nome do Subagente | Especialidade Principal |
| :--- | :--- | :--- |
| **Backend** | `backend-agent` | FastAPI, Python, Pydantic, SQLAlchemy, regras de negócio e APIs REST |
| **Frontend** | `frontend-agent` | React, TypeScript, Tailwind CSS v4, Padrão GIO, Acessibilidade e UX |
| **Cibersegurança** | `security-agent` | OWASP Top 10, proteção contra invasões, JWT, sanitização e SecOps |
| **Qualidade (QA)** | `qa-agent` | Testes automatizados (Vitest/pytest), regressão, edge cases e estabilidade |
| **Banco de Dados** | `database-agent` | Schemas relacionais, consultas SQL, índices, ETL e consistência contábil |
| **DevOps / Infra** | `devops-agent` | GitFlow, CI/CD, governança de branches, validação de build e deploy |

Os agentes estão registrados no runtime do Antigravity e podem ser acionados individualmente ou em conjunto para missões especializadas.
